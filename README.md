# GameByte

Tienda online de videojuegos, informática y anime.
Proyecto de Desarrollo de Aplicaciones Multiplataforma (CIFP Virgen de Gracia).

## Componentes
- `api/`: servidor API REST (Java, Spring Boot, MySQL)
- `movil/`: app móvil para clientes (Android, Kotlin, Jetpack Compose)
- `escritorio/`: app de gestión (Java, JavaFX)
- `docs/`: documentación, diagramas y pantallazos
